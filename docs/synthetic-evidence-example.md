# Synthetic evidence example

**Illustrative only.** This example was written specifically for this public showcase. It is not an actual incident, extracted document, test record, or result from the private application.

## Fictional source note

> A demonstration motor did not accelerate during a commanded start. No current trace, relay event, or mechanical inspection result is available in this example.

## How an evidence-aware knowledge card should frame it

| Field | Illustrative content |
| --- | --- |
| Documented observation | The note reports that acceleration did not occur during the start attempt. |
| Possible interpretation | More than one electrical or mechanical explanation may fit the observation. |
| Unknowns | Supply conditions, current, protection operation, shaft/load condition, and test results. |
| Evidence limit | The note alone does not identify a root cause. |
| Useful follow-up | Obtain the relevant event and measurement records through the applicable authorized procedure. |

## Example question

**Can the note establish that a protection relay caused the unsuccessful start?**

**Evidence-limited answer:** No. The example provides neither a relay event nor other evidence that establishes relay operation. The cause remains undetermined.

## Why it matters

A knowledge system should help an engineer identify the next evidence needed. Turning an incomplete observation into a confident failure diagnosis would weaken the engineering value of the answer.

This manually authored example explains the intended evidence discipline; it is not a benchmark or a captured AI output.
